В мире удаленного доступа давно царят монстры вроде TeamViewer и AnyDesk. Это мощные, но не всегда удобные решения. Из глобальных минусов можно выделить дорогие лицензии для коммерческого использования и зависимость от чужих серверов. Поэтому сегодня мы поговорим об очень достойной альтернативе, которая не просто догоняет, но и во многом превосходит выше перечисленные программы. 

RustDesk — это кроссплатформенное решение для удаленного рабочего стола с открытым исходным кодом, написанное, как несложно догадаться, на Rust. В этой статье мы не только познакомимся с его возможностями, но и настроим собственный сервер на Linux, чтобы получить полную независимость и безопасность.
![[rustdesk_home.png]]
### Почему именно RustDesk?

На первый взгляд интерфейс RustDesk минималистичен, но под этой простотой скрывается достаточно обширный функционал. Помимо базового удаленного управления с отличной отзывчивостью даже на не самых быстрых каналах, вы получаете полный набор инструментов для эффективной работы. Это и бесшовная передача файлов, работающая в обе стороны, и синхронизация буфера обмена, которая позволяет легко копировать текст и данные между машинами. Для командной работы и удаленной поддержки незаменимым окажется встроенный текстовый и голосовой чаты, а для демонстраций или документирования — функция записи всей сессии.

Rustdesk базируется на 3 главных принципах:
- **Открытый исходный код (Open Source).** Весь код проекта открыт для проверки. Это означает, что сотни независимых экспертов и энтузиастов по всему миру постоянно изучают его на предмет уязвимостей. Здесь нет скрытых бэкдоров, необъявленных функций сбора данных или сомнительных алгоритмов шифрования — только полная прозрачность.
    
- **Сквозное шифрование (End-to-End Encryption).** Все данные между вашими клиентами — видео, аудио, файлы, нажатия клавиш — защищены современными алгоритмами сквозного шифрования. Даже если вы используете публичные серверы RustDesk, разработчики не могут перехватить ваш трафик. А при настройке собственного сервера вы и вовсе становитесь единственным владельцем всей инфраструктуры.
    
- **Полный контроль с Self-Hosting.** Это безопасность на уровне железа. Развернув свои серверы `hbbs` (Rendezvous Server) и `hbbR` (Relay Server), вы полностью изолируете свой трафик удаленного доступа от интернета. Ваши пароли, сессионные ключи и рабочие данные никогда не покидают вашу контролируемую среду. Это решение уровня предприятий, доступное каждому.

### Настройка собственного сервера RustDesk на Linux

Предположим, у нас есть чистый сервер на Ubuntu 20.04/22.04 с белым IP-адресом. Мы хотим сделать его нашим хабом для RustDesk.

#### Шаг 1 Подготовка сервера

Обновляем систему и устанавливаем необходимые зависимости.

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y wget curl
```

#### Шаг 2 Скачивание и установка серверных бинарников

Заходим на [страницу релизов RustDesk](https://github.com/rustdesk/rustdesk-server/releases) и скачиваем последнюю стабильную версию серверного ПО. На момент написания статьи это версия 1.1.15.

```bash
# Создаем директорию для RustDesk
sudo mkdir /opt/rustdesk-server
cd /opt/rustdesk-server

# Скачиваем архив
sudo wget https://github.com/rustdesk/rustdesk-server/releases/latest/download/rustdesk-server-linux-amd64.zip

# Устанавливаем unzip для распаковки
sudo apt install -y unzip

# Распаковываем архив
sudo unzip rustdesk-server-linux-amd64.zip

# Даем права на выполнение
sudo chmod +x amd64/hbbs amd64/hbbr
```

#### Шаг 3 Настройка фаервола

Нам нужно открыть несколько портов для работы сервиса. Обязательные:
*   **21115-21119 TCP** — используются для слушающих сокетов.
*   **21116 UDP** — используется для проверки состояния сервера и ID.

```bash
sudo ufw allow 21115:21119/tcp
sudo ufw allow 21116/udp
```

#### Шаг 4 Запуск серверов

Запустим наши `hbbs` и `hbbr` в фоновом режиме. Ключ `-k _` отключает требование пароля для неавторизованных подключений (для теста, в продакшене лучше задать пароль).

```bash
# Запускаем hbbs (Rendezvous Server)
cd /opt/rustdesk-server/amd64
sudo ./hbbs -r rustdesk.example.com:21117 -k _

# Запускаем hbbr (Relay Server)
sudo ./hbbr -k _
```

*   **Важно:** Замените `rustdesk.example.com` на реальный IP-адрес или доменное имя вашего сервера. Параметр `-r` указывает клиентам, куда подключаться для ретрансляции.

#### Шаг 5 Автозапуск серверов

Чтобы сделать запуск сервисов постоянным, лучше всего создать systemd-юниты.

Создаем сервис для hbbs:
```bash
sudo nano /etc/systemd/system/rustdesk-hbbs.service
```

Добавляем содержимое:
```ini
[Unit]
Description=RustDesk HBBS (Rendezvous Server)
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/rustdesk-server/amd64
ExecStart=/opt/rustdesk-server/amd64/hbbs -r rustdesk.example.com:21117 -k _
Restart=always
RestartSec=5
User=root

[Install]
WantedBy=multi-user.target
```

Создаем сервис для hbbr:
```bash
sudo nano /etc/systemd/system/rustdesk-hbbr.service
```

Добавляем содержимое:
```ini
[Unit]
Description=RustDesk HBBR (Relay Server)
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/rustdesk-server/amd64
ExecStart=/opt/rustdesk-server/amd64/hbbr -k _
Restart=always
RestartSec=5
User=root

[Install]
WantedBy=multi-user.target
```

Теперь включаем и запускаем сервисы:
```bash
sudo systemctl daemon-reload
sudo systemctl enable rustdesk-hbbs.service rustdesk-hbbr.service
sudo systemctl start rustdesk-hbbs.service rustdesk-hbbr.service
```

Проверить их статус можно командами:
```bash
sudo systemctl status rustdesk-hbbs.service
sudo systemctl status rustdesk-hbbr.service
```

#### Шаг 5 Копирование публичного ключа

После первого запуска `hbbs` в директории `/opt/rustdesk-server/amd64` появятся два ключевых файла:
*   `id_ed25519.pub` — **публичный ключ**
*   `id_ed25519` — **приватный ключ**

Нам понадобится содержимое публичного ключа для настройки клиентов.

Посмотреть его можно так:
```bash
sudo cat /opt/rustdesk-server/amd64/id_ed25519.pub
```
Скопируйте эту строку, она нам пригодится.

### Настройка клиента для подключения к своему серверу

1.  Скачайте и установите клиент RustDesk на свое устройство с [официального сайта](https://rustdesk.com/).
2.  В главном окне клиента нажмите на кнопку с тремя точками (⋮) рядом с ID.
3.  Перейдите во вкладку «Сеть» и разблокируйте настройки.
4.  В разделе «ID-сервер» введите ip-адрес или домен вашего сервера.
5.  В разделе «Relay server» введите те же значения, что и у «ID-сервер».
6.  В поле «Ключ» вставьте тот самый **публичный ключ** из файла `id_ed25519.pub`.
7.  Нажмите «OK».
![[rustdesk_network.png]]
Готово! Теперь ваш клиент будет использовать ваш собственный сервер для установки соединения.

## Заключение

RustDesk — это достойная программа для удаленного доступа с достаточно обширным функционалом. Потратив менее 30 минут на настройку, вы получаете безопасную и полностью контролируемую систему удаленного доступа, которая не уступит дорогим коммерческим продуктам.
